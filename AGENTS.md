# Project Rules

The project is currently in this phase:

Product Spec
→ Epic
→ User Story
↔ UI / Screen / User Flow

All feature, business, and UI changes must keep documentation and UI consistent.

When modifying UI, identify the related User Story, then check its Epic and relevant Product Spec section.

When modifying Product Spec, Epic, or User Story, check whether related documentation and UI are affected.

Follow the detailed synchronization rules in:

`.agents/rules/docs-sync.md`

Do not create Acceptance Criteria, API, database, technical design, or implementation unless explicitly requested.

Do not modify or rewrite unrelated artifacts.

Do not consider a task complete while affected artifacts are inconsistent.
