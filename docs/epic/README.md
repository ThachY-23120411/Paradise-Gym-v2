# Epic theo Role

Epic không còn được quản lý như một danh sách menu dùng chung duy nhất. Epic canonical được phân theo role và platform:

- [`qtv/`](qtv/) — QTV / Quản lý — Web only.
- [`le-tan/`](le-tan/) — Lễ tân — Web only.
- [`hoi-vien/`](hoi-vien/) — Hội viên — Mobile only; Epic chính là footer menu HV01–HV04.
- [`pt/`](pt/) — Huấn luyện viên — Mobile only; Epic chính là footer menu PT01–PT04.

Mỗi Epic role có User Story riêng trong thư mục tương ứng của `docs/user-stories/`. Không đưa chức năng của role khác hoặc platform khác vào Epic role đó.
