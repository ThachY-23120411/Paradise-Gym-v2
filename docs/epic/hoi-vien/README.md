# Epics Mobile — Hội viên

Role `Hội viên` chỉ sử dụng **Mobile**. Năm Epic dưới đây chính là các mục navigation trên Mobile App (`fe/src/mobile.tsx`):

| Epic | Phân loại | Chức năng chính |
| --- | --- | --- |
| [HV01](HV01-Trang%20chủ.md) | Footer menu `Trang chủ` | Tổng quan, việc cần xử lý, lịch sắp tới, điều hướng nhanh |
| [HV02](HV02-Lịch%20tập.md) | Footer menu `Lịch tập` | Xem lịch, đặt lịch PT, hủy lịch, xác nhận buổi tập |
| [HV03](HV03-Gói%20của%20tôi.md) | Footer menu `Gói của tôi` | Xem/mua gói, thanh toán, quyền lợi, chọn PT, lịch sử payment |
| [HV04](HV04-Tài%20khoản.md) | Footer menu `Tài khoản` | Quản lý hồ sơ cá nhân, đổi SĐT qua OTP, cấu hình thông báo & bảo mật 2FA |
| [HV05](HV05-Thông%20báo.md) | Footer menu `Thông báo` | Nhận thông báo tự động, lọc chưa đọc, mở rộng chi tiết tại chỗ |
| [HV06](HV06-Đăng%20nhập.md) | Module Xác thực (Auth) | Đăng nhập đa phương thức, Xác thực 2 lớp (2FA), Kích hoạt bằng OTP, Đăng xuất |

Không tạo Epic Mobile cho QTV hoặc Lễ tân. Hai role đó chỉ có namespace Web riêng.
