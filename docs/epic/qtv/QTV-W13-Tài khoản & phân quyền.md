# QTV-W13 — Tài khoản & phân quyền

- **Role:** QTV / Quản lý
- **Platform:** Web only
- **Menu:** `W13`
- **Goal:** Quản lý xem danh sách tài khoản, thống kê KPI và sửa thông tin tài khoản (trạng thái, vai trò, phạm vi chi nhánh).
- **Scope:** Xem danh sách tài khoản, 4 thẻ KPI thống kê, tìm kiếm SĐT/tên người dùng, lọc theo vai trò/trạng thái; chỉnh sửa trạng thái tài khoản, vai trò (đa vai trò) và phạm vi chi nhánh.
