# QTV-W11 — Chi nhánh

- **Role:** QTV cấp tối cao (Quản trị viên - Toàn chuỗi / cơ sở mẹ)
- **Platform:** Web only
- **Menu:** `W11`
- **Goal:** Quản lý danh sách chi nhánh trong hệ thống, thêm chi nhánh mới, chỉnh sửa thông tin chi nhánh và xem số liệu thống kê vận hành từng chi nhánh.
- **Scope:** Xem danh sách các Card chi nhánh kèm 3 chỉ số tổng quan (Hội viên, Huấn luyện viên, Đang tập); Thêm chi nhánh mới; Chỉnh sửa thông tin chi nhánh; Xem số liệu vận hành chi tiết. Độc quyền chỉ dành riêng cho QTV cấp tối cao (Quản trị viên - Toàn chuỗi).
