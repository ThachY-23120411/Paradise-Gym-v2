# QTV-W05 — Huấn luyện viên

- **Role:** QTV / Quản lý
- **Platform:** Web only
- **Menu:** `W05`
- **Goal:** Quản lý hồ sơ PT, trạng thái hoạt động và tra cứu danh sách PT trong phạm vi chi nhánh.
