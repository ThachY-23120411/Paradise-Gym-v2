## Diagram convention

Mỗi diagram dùng Mermaid `flowchart TB` hoặc `flowchart LR`; diagram phải có boundary platform/feature, swimlane theo role/actor/SYS, node initial/action/decision/merge/join/final khi flow yêu cầu và label cho mọi nhánh quyết định. Bản ghi nghiệp vụ cần lịch sử không bị xóa vật lý.
