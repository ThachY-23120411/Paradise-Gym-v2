# User Stories Mobile — Hội viên

- **Role:** Hội viên
- **Platform:** Mobile only
- **Canonical namespace:** `docs/user-stories/hoi-vien/`

Cấu trúc canonical:

```text
Hội viên → Mobile → Epic/Menu footer → User Story → Activity Diagram → UI Screen
```

Mỗi Epic có một thư mục riêng; các User Story của Epic được đặt bên trong thư mục đó. Mỗi file User Story có flow chính, alternate/exception flow, permission/data scope và activity diagram Mermaid swimlane.
