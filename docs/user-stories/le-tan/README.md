# User Stories Web — Lễ tân

- **Role:** Lễ tân
- **Platform:** Web only
- **Canonical namespace:** `docs/user-stories/le-tan/`

Cấu trúc canonical:

```text
Lễ tân → Web → Epic/Menu → User Story → Activity Diagram → UI Screen
```

Mỗi Epic có một thư mục riêng; các User Story của Epic được đặt bên trong thư mục đó. Mỗi file User Story mô tả một chức năng của menu Web tương ứng, gồm flow chính, flow thay thế, exception flow, scope quyền dữ liệu và activity diagram Mermaid có swimlane.
